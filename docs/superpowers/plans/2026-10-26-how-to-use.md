# How to use page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a capture-desk page that tells a person, in order, how to use the desk that exists today.

**Architecture:** The sentences live in one content module. A page component renders them as numbered steps, then appends the existing install steps so those commands stay in one place. The page is the hash route `#/guide`. The top bar and the desk menu both open it. No new storage, no pack-format change, and no behavior change outside navigation.

**Tech Stack:** TypeScript, Vitest, React 19, the existing hash router in `apps/capture/src/route.ts`, and the CSS variables already used by the desk.

## Global Constraints

- Local-first version 1. The page must not mention accounts, hosted storage, sync, telemetry, encryption, or IndexedDB.
- Audio files are not transcribed. Dictation is the microphone through Web Speech.
- A PDF or text file fills the note field. It does not save until the person presses Enter or Add.
- Clear ledger deletes notes and custom shelves only. LLM settings and the color mode stay.
- The color control is a switch named Dark mode. The first visit is light. The desk does not follow the operating system.
- Do not edit `AGENTS.md` or `docs/agent-kb/` in these tasks. After the last task, ask whether those files need a sentence about the how-to page.
- Commit only the files named in that task. Never `git add -A`. This checkout has unrelated uncommitted desk edits. If a named file already contains those edits, copy it aside, restore the committed version, apply only this task, commit, then restore the working copy and re-apply this task's edits on top.
- Keep committed file modes at `100644`. After `git add`, run `git update-index --chmod=-x` on each added file and confirm `git ls-files -s` shows `100644` before committing.
- Do not change the pack format.

## File structure

- `apps/capture/src/lib/howTo.ts` — the instruction sections. One responsibility: the words.
- `apps/capture/src/lib/howTo.test.ts` — locks the claims that must stay true.
- `apps/capture/src/components/HowTo.tsx` — renders the sections and the existing install steps.
- `apps/capture/src/components/HowTo.test.tsx` — renders the page heading and one step from each source.
- `apps/capture/src/route.ts` — `{ view: "guide" }` for `#/guide`.
- `apps/capture/src/route.test.ts` — the new hash.
- `apps/capture/src/App.tsx` — renders the page, and links it from the top bar and the desk menu.
- `apps/capture/src/App.test.tsx` — opens the page from both links.
- `apps/capture/src/styles.css` — layout for the instruction page, using existing variables only.

```ts
export type DeskRoute =
  | { view: "hub" }
  | { view: "ledger" }
  | { view: "audio" }
  | { view: "install" }
  | { view: "guide" }
  | { view: "shelf"; slug: string };

export function parseRoute(hash: string): DeskRoute {
  if (hash === "#/ledger") return { view: "ledger" };
  if (hash === "#/audio") return { view: "audio" };
  if (hash === "#/install") return { view: "install" };
  if (hash === "#/guide") return { view: "guide" };
  const match = /^#\/shelf\/([^/?#]+)/.exec(hash);
```
